Variables let one approved WhatsApp template use different values for each recipient. Before sending, make sure every selected contact has a value for every variable shown in the template.

For example, `Hello {{1}}, your appointment is on {{2}}.` needs two values for each contact.

## Use Variables in an Uploaded File

<Steps>
  <Step title="Check the template variables">
    Select the **Template message** and review the **Message preview**. Numbered variables appear as `{{1}}`, `{{2}}`, and so on.

    ![Message preview with template variables highlighted](/images/broadcasts/template-variables-message-preview.jpeg)
  </Step>
  <Step title="Add one column for each variable">
    In the CSV or Excel file, add a column whose header matches each numbered variable exactly. Fill every variable cell for every recipient.

    ![Spreadsheet with Name, Phone, and numbered variable columns for each contact](/images/broadcasts/prepare-broadcast-variables.jpeg)

    | Name | Phone | &#123;&#123;1&#125;&#125; | &#123;&#123;2&#125;&#125; |
    | --- | --- | --- | --- |
    | Aisha | 919876543210 | Aisha | 20 August |

    <Note>
      Select **Sample CSV** or **Sample Excel** in **Upload a list** when you need a file with the expected structure.
    </Note>
  </Step>
  <Step title="Upload and validate the values">
    Select **Choose file** and upload the prepared file. Eazybe displays **Variable data loaded successfully** when it can read the variable data.

    ![Uploaded variable contact list with Variable data loaded successfully and Replace file](/images/broadcasts/review-and-send-broadcast.jpeg)
  </Step>
</Steps>

## Use Variables with a HubSpot Segment

Select a template with numbered variables and choose a **HubSpot segment**. The **Map template variables to HubSpot** panel lets you set the property and fallback for each variable, including when you use a **Workspace variable template**.

| Selected segment | Available mapping properties |
| --- | --- |
| **Contacts** | **Contact properties** |
| **Deals** | **Deal properties** |

For every numbered variable, open **Choose a HubSpot property**, search for the field, and select it. Enter a **Fallback value (required)**. The fallback is used when the mapped property is empty.

For a deal segment, the message uses mapped deal properties and is delivered to the contacts associated with those deals. After switching segment types, review the mappings and fallbacks for the newly selected segment.

The panel also appears for **HubSpot property templates** and **Zoho variable templates** that contain numbered variables. Review any suggested mapping before sending. Every variable needs a property and a fallback; these selections apply only to the current broadcast and do not change saved template mappings.

See [Broadcast to a HubSpot Contact or Deal Segment](/en/broadcasts/hubspot-contact-list) for segment selection and eligible-contact counts.
