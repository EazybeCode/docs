---
title: "Create Eazybe Broadcast Reports in HubSpot"
description: "Create success and failure-reason broadcast reports using Eazybe contact properties."
---

Use this guide to create two client-ready HubSpot reports from these Eazybe contact properties:

- **Eazybe Last Broadcast Status**
- **Eazybe Last Broadcast Failure Reason**
- **Eazybe Last Broadcast At**

## Open the HubSpot report builder

<Steps>
  <Step title="Open Reports">
    In your HubSpot account, click the **Reporting** icon in the left navigation, then select **Reports**.

    <Frame caption="HubSpot Reports page">
      <img src="/images/hubspot-broadcast-reports-page.png" alt="HubSpot Reports page with the Create button" />
    </Frame>
  </Step>

  <Step title="Create a report">
    Click **Create** in the upper-right corner, then select **Create report**.

    <Frame caption="Create a report from the HubSpot Reports page">
      <img src="/images/hubspot-broadcast-create-report.png" alt="HubSpot Reports page with the Create menu open and Create report highlighted" />
    </Frame>
  </Step>

  <Step title="Choose the custom report builder">
    Select **Custom report builder**, then click **Next**.

    <Frame caption="Choose the HubSpot custom report builder">
      <img src="/images/hubspot-broadcast-custom-report-builder.png" alt="HubSpot Create report page with the Custom report option selected" />
    </Frame>
  </Step>

  <Step title="Select the data source">
    Select **Contacts** as the primary data source, then click **Next**.

    <Frame caption="Select Contacts as the primary data source">
      <img src="/images/hubspot-broadcast-select-data-source.png" alt="HubSpot Choose data sources page with Contacts selected as the primary data source" />
    </Frame>
  </Step>

  <Step title="Find the Eazybe properties">
    In the search field, enter **Eazybe Last Broadcast**. The matching Eazybe properties will appear in the field list.

    <Frame caption="Eazybe properties in the HubSpot report builder">
      <img src="/images/hubspot-broadcast-report-builder.png" alt="HubSpot custom report builder showing Eazybe broadcast properties" />
    </Frame>
  </Step>
</Steps>

## Report 1: Broadcast success by month

This report shows how many contacts had a successful broadcast result each month.

<Steps>
  <Step title="Choose the chart">
    Under **Visualization**, select **Vertical bar**.

    <Frame caption="Choose the vertical bar chart visualization">
      <img src="/images/hubspot-broadcast-choose-vertical-bar-chart.png" alt="HubSpot custom report builder with the Visualization menu open and Vertical bar highlighted" />
    </Frame>
  </Step>

  <Step title="Set the X-axis">
    Drag **Eazybe Last Broadcast At** to the **X-axis**. Click the edit icon beside the field and select **Monthly** as the frequency.

    <Frame caption="Set Eazybe Last Broadcast At as the monthly X-axis">
      <img src="/images/hubspot-broadcast-set-x-axis.png" alt="HubSpot custom report builder with Eazybe Last Broadcast At configured as the monthly X-axis" />
    </Frame>
  </Step>

  <Step title="Set the Y-axis">
    Search for **Count of contacts** and drag it to the **Y-axis**.

    <Frame caption="Set Count of contacts as the Y-axis">
      <img src="/images/hubspot-broadcast-set-y-axis.png" alt="HubSpot custom report builder with Count of contacts configured as the Y-axis" />
    </Frame>
  </Step>

  <Step title="Add the status breakdown">
    Drag **Eazybe Last Broadcast Status** to **Break down by**.

    <Frame caption="Break down the chart by broadcast status">
      <img src="/images/hubspot-broadcast-add-status-breakdown.png" alt="HubSpot custom report builder with Eazybe Last Broadcast Status configured as the chart breakdown" />
    </Frame>
  </Step>

  <Step title="Apply the success filters">
    Open **Filters** and add all of the following:

    - **Eazybe Last Broadcast At** is known
    - **Eazybe Last Broadcast Status** is any of **Delivered** or **Read**

    <Frame caption="Filter the report for successful broadcasts">
      <img src="/images/hubspot-broadcast-apply-success-filters.png" alt="HubSpot report filters with Eazybe Last Broadcast At and the Delivered and Read broadcast statuses selected" />
    </Frame>
  </Step>

  <Step title="Save the report">
    Click **Save report** and use the name **Eazybe Broadcast Success by Month**.
  </Step>
</Steps>

<Frame caption="Example of a saved broadcast status report">
  <img src="/images/hubspot-broadcast-success-chart.png" alt="HubSpot chart showing contact counts by broadcast status" />
</Frame>

## Report 2: Broadcast failure reasons by month

This report shows why broadcasts failed and how frequently each reason occurred.

<Steps>
  <Step title="Create another custom report">
    Return to **Reports**, click **Create**, select **Create report**, choose **Custom report builder**, and use **Contacts** as the primary data source.

    <Frame caption="Create another custom report in HubSpot">
      <img src="/images/hubspot-broadcast-create-another-custom-report.jpeg" alt="HubSpot Create report page with Custom report selected and the Next button highlighted" />
    </Frame>
  </Step>

  <Step title="Choose the chart">
    Under **Visualization**, select **Vertical bar**.

    <Frame caption="Choose the vertical bar chart for the failure-reasons report">
      <img src="/images/hubspot-broadcast-failure-choose-vertical-bar.jpeg" alt="HubSpot custom report builder with Vertical bar selected in the Visualization menu" />
    </Frame>
  </Step>

  <Step title="Set the X-axis">
    Drag **Eazybe Last Broadcast At** to the **X-axis**, then set its frequency to **Monthly**.

    <Frame caption="Set the monthly X-axis for the failure-reasons report">
      <img src="/images/hubspot-broadcast-failure-set-x-axis.jpeg" alt="HubSpot custom report builder with Eazybe Last Broadcast At added to the X-axis and displayed monthly" />
    </Frame>
  </Step>

  <Step title="Set the Y-axis">
    Drag **Count of contacts** to the **Y-axis**.

    <Frame caption="Set Count of contacts as the Y-axis for the failure-reasons report">
      <img src="/images/hubspot-broadcast-failure-set-y-axis.jpeg" alt="HubSpot custom report builder with Count of contacts added to the Y-axis" />
    </Frame>
  </Step>

  <Step title="Add the failure-reason breakdown">
    Drag **Eazybe Last Broadcast Failure Reason** to **Break down by**.

    <Frame caption="Break down the report by broadcast failure reason">
      <img src="/images/hubspot-broadcast-failure-add-breakdown.jpeg" alt="HubSpot custom report builder with Eazybe Last Broadcast Failure Reason added to Break down by" />
    </Frame>
  </Step>

  <Step title="Apply the failure filters">
    Open **Filters** and add all of the following:

    - **Eazybe Last Broadcast Status** is equal to **Failed**
    - **Eazybe Last Broadcast At** is known
    - **Eazybe Last Broadcast Failure Reason** is known

    <Frame caption="Apply the failure filters to the report">
      <img src="/images/hubspot-broadcast-apply-failure-filters.jpeg" alt="HubSpot report configured with Failed status, known broadcast date, and known failure reason filters" />
    </Frame>
  </Step>

  <Step title="Save the report">
    Click **Save report** and use the name **Eazybe Broadcast Failure Reasons by Month**.

    <Frame caption="Save the broadcast failure-reasons report">
      <img src="/images/hubspot-broadcast-save-failure-reasons-report.png" alt="HubSpot Save report panel with Eazybe Broadcast Failure Reasons by Month entered as the report name" />
    </Frame>
  </Step>
</Steps>

<Note>
If the report displays no data, confirm that **Count of contacts** is on the Y-axis for chart reports and that the selected contacts have values in the Eazybe properties.
</Note>

## Add the reports to a dashboard

When saving each report, select an existing dashboard or create a new dashboard named **Eazybe Broadcast Performance**. Add both reports so clients can review success trends and failure reasons from one place.
