Admins and managers can start a one-to-one conversation from Team Inbox by sending an approved WhatsApp Business API template. Acquisition lists then help eligible users review conversations connected to advertisements and broadcast workflows.

## Start a new chat

The **+** button beside **Search conversations** opens the new-chat flow. It is not shown to Employee-role users.

<Steps>
  <Step title="Select the recipient">
    Choose a country code and enter the customer's local phone number, or search and select an existing contact found in your available conversations.

    <Info>
      **Add image here:** Add a screenshot showing the country picker, phone field, and existing-contact search. Save it as `/images/team-inbox/new-chat-select-recipient.png`.
    </Info>
  </Step>
  <Step title="Check the full number">
    Review the country code and phone number together. A manually entered local number must contain at least seven digits after formatting is removed.

    <Info>
      **Add image here:** Add a screenshot showing the completed recipient number before continuing. Save it as `/images/team-inbox/new-chat-check-number.png`.
    </Info>
  </Step>
  <Step title="Choose the sender">
    Select one of the connected WABA numbers available to you. If only one eligible number is available, Team Inbox selects it automatically.

    <Info>
      **Add image here:** Add a screenshot showing the connected WABA sender choices. Save it as `/images/team-inbox/new-chat-choose-sender.png`.
    </Info>
  </Step>
  <Step title="Choose Template & Send">
    Open the approved templates belonging to that sender.

    <Info>
      **Add image here:** Add a screenshot showing the Choose Template & Send control. Save it as `/images/team-inbox/new-chat-choose-template.png`.
    </Info>
  </Step>
  <Step title="Complete variables">
    Fill every required variable and check the message preview, language, header media, footer, and buttons.

    <Info>
      **Add image here:** Add a screenshot showing the template preview and completed variable fields. Save it as `/images/team-inbox/new-chat-complete-variables.png`.
    </Info>
  </Step>
  <Step title="Send the template">
    Click **Send Template**. Team Inbox creates or opens the conversation after the template is sent successfully.

    <Info>
      **Add image here:** Add a screenshot showing the final Send action and opened conversation. Save it as `/images/team-inbox/new-chat-send-template.png`.
    </Info>
  </Step>
</Steps>

<Warning>
  A new WABA conversation must begin with an approved template. A normal text message cannot be used for the first message.
</Warning>

If no sender is available, connect a WABA number or ask an admin to check your channel access and number mapping.

## Review advertisement conversations

The **Advertisement** list appears under **Acquisition** for eligible non-Employee users.

<Steps>
  <Step title="Open Advertisement">
    Expand **Acquisition** and select **Advertisement**.

    <Info>
      **Add image here:** Add a screenshot showing Acquisition and Advertisement in Lists. Save it as `/images/team-inbox/acquisition-open-advertisement.png`.
    </Info>
  </Step>
  <Step title="Choose a number scope">
    Select **All numbers** or one available WABA number.

    <Info>
      **Add image here:** Add a screenshot showing All numbers and WABA choices. Save it as `/images/team-inbox/acquisition-choose-ad-number.png`.
    </Info>
  </Step>
  <Step title="Choose an advertisement">
    Select an ad to display the conversations attributed to it.

    <Info>
      **Add image here:** Add a screenshot showing the advertisement choices. Save it as `/images/team-inbox/acquisition-choose-ad.png`.
    </Info>
  </Step>
  <Step title="Open a customer conversation">
    Select a result to read and manage it without leaving the acquisition view.

    <Info>
      **Add image here:** Add a screenshot showing an ad-filtered conversation list and open conversation. Save it as `/images/team-inbox/acquisition-open-ad-conversation.png`.
    </Info>
  </Step>

The ad selector shows loading, no-ad, and error states when appropriate. A disconnected indicator identifies a source number that needs attention.

## Review broadcast-workflow conversations

The **Broadcast** list appears under **Acquisition** when the user has Broadcast permission.

<Steps>
  <Step title="Open Broadcast">
    Expand **Acquisition** and select **Broadcast**.

    <Info>
      **Add image here:** Add a screenshot showing Acquisition and Broadcast in Lists. Save it as `/images/team-inbox/acquisition-open-broadcast.png`.
    </Info>
  </Step>
  <Step title="Choose the WABA number">
    Select the number used for the broadcast.

    <Info>
      **Add image here:** Add a screenshot showing the broadcast WABA selector. Save it as `/images/team-inbox/acquisition-choose-broadcast-number.png`.
    </Info>
  </Step>
  <Step title="Choose the workflow">
    Select a broadcast workflow. Its summary can show sent and replied counts.

    <Info>
      **Add image here:** Add a screenshot showing workflow choices with sent and replied counts. Save it as `/images/team-inbox/acquisition-choose-workflow.png`.
    </Info>
  </Step>
  <Step title="Choose a result tab">
    Use **All chats** to see every conversation from the workflow, or **Replied** to focus on customers who responded.

    <Info>
      **Add image here:** Add a screenshot showing All chats and Replied with their result counts. Save it as `/images/team-inbox/acquisition-broadcast-tabs.png`.
    </Info>
  </Step>

<Note>
  The Broadcast list is for reviewing conversations connected to an existing broadcast workflow. Whether broadcast creation and other broadcast tools are available depends on the workspace configuration and the member's Broadcast permission.
</Note>

This control is session-dependent and is not part of the normal employee workflow.

## Common reasons a new chat cannot start

- The phone number is incomplete or has the wrong country code.
- No connected WABA number is available to you.
- The selected WABA became unavailable while the dialog was open.
- No approved template belongs to the selected sender.
- One or more required template variables are blank.
- Your role or channel permissions do not allow the action.
