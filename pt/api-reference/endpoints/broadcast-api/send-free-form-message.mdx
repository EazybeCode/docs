## Enviar mensagem de formato livre

Envia uma única mensagem para um destinatário. Todos os oito tipos de conteúdo compartilham este endpoint — o campo `type` decide quais outros campos são obrigatórios.

### Endpoint

```http
POST /broadcast/public/send-freeform
```

### Campos comuns

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `fromPhoneNumber` | corda | Obrigatório | Seu número WABA |
| `toPhoneNumber` | corda | Obrigatório | Destinatário com código do país, apenas dígitos |
| `type` | corda | Obrigatório | Um dos oito tipos abaixo |

### Campos específicos do tipo

| `type` | Obrigatório | Opcional | Extensões de arquivo aceitas |
| --- | --- | --- | --- |
| `text` | `text` | — | — |
| `image` | `url` | `caption` | jpg, jpeg, png |
| `document` | `url` | `name`, `caption` | pdf, txt, doc, docx, ppt, pptx, xls, xlsx |
| `audio` | `url` | — | aac, amr, mp3, m4a, mp4, ogg, opus |
| `video` | `url` | `caption` | mp4, 3gp |
| `sticker` | `url` | — | webp |
| `location` | `latitude`, `longitude` | `name`, `address` | — |
| `interactive` | `interactive` | — | — |

<Warning>
  **A extensão é lida a partir do caminho do URL, não do arquivo.** Um PNG real servido a partir de um URL que termina em `.webp` é rejeitado para `image`, e um URL sem extensão é rejeitado para cada tipo de mídia. As strings de consulta são ignoradas, então `…/photo.png?v=2` está bem.
</Warning>

### Texto

```json
{
  "fromPhoneNumber": "14844634680",
  "toPhoneNumber": "919675360316",
  "type": "text",
  "text": "Your order #4821 has shipped."
}
```

### Localização

`latitude` e `longitude` devem ser números JSON, não strings. A latitude aceita −90 a 90, longitude −180 a 180.

```json
{
  "fromPhoneNumber": "14844634680",
  "toPhoneNumber": "919675360316",
  "type": "location",
  "latitude": 28.4595,
  "longitude": 77.0266,
  "name": "Eazybe HQ",
  "address": "Sector 44, Gurugram, Haryana 122003"
}
```

### Interativo — botões

Até **3** botões de resposta. Mais de três são rejeitados.

```json
{
  "fromPhoneNumber": "14844634680",
  "toPhoneNumber": "919675360316",
  "type": "interactive",
  "interactive": {
    "type": "button",
    "header": { "type": "text", "text": "Renew your plan" },
    "body": { "text": "Your subscription ends in 3 days. Renew now?" },
    "footer": { "text": "Reply STOP to opt out" },
    "action": {
      "buttons": [
        { "type": "reply", "reply": { "id": "renew_yes", "title": "Renew now" } },
        { "type": "reply", "reply": { "id": "renew_later", "title": "Remind me later" } }
      ]
    }
  }
}
```

### Interativo — lista

Até **10** linhas contadas em *todas* as seções combinadas, não por seção.

```json
{
  "fromPhoneNumber": "14844634680",
  "toPhoneNumber": "919675360316",
  "type": "interactive",
  "interactive": {
    "type": "list",
    "header": { "type": "text", "text": "Pick a plan" },
    "body": { "text": "Choose the plan that fits your team." },
    "action": {
      "button": "View plans",
      "sections": [
        {
          "title": "Monthly",
          "rows": [
            { "id": "starter_m", "title": "Starter", "description": "3 seats included" },
            { "id": "growth_m", "title": "Growth", "description": "10 seats included" }
          ]
        }
      ]
    }
  }
}
```

### Resposta

**200 — mesmo formato para todos os oito tipos**

```json
{
  "status": true,
  "status_code": 200,
  "message": "Free-form message queued successfully",
  "data": { }
}
```
