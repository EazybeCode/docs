## Use the User profile

The User profile contains three tabs:

| Tab | Use it for |
|---|---|
| **Profile** | Review AI insights and configured customer properties. |
| **Follow-up** | Add customer notes and optionally schedule a reminder. |
| **Task** | Create, assign, prioritize, track, and complete customer tasks. |

The panel header shows the customer's name and phone number. Close the panel with **x** when you need more room for the conversation.

## Switch to HubSpot

Select the HubSpot icon in the customer-details header. The available state depends on the integration and the current chat:

| State | What to do |
|---|---|
| **HubSpot is not connected** | Use the connection prompt or ask an admin to connect the integration. |
| **No contact is linked** | Search HubSpot for the correct person, link a result, or create a contact from the current chat. |
| **A contact is linked** | Work with About, Notes, Tasks, and Calls without leaving Team Inbox. |
| **Data failed to load** | Use the retry action. |

## Correct a wrong HubSpot link

If the linked record belongs to someone else, select **Not Right Contact?** to unlink it, then search for or create the correct contact.

This action requires permission to edit customer/CRM information.

## Understand edit permissions

The **User Properties** permission controls editing of supported Eazybe customer data and HubSpot mini-CRM data. A user without permission can still view supported CRM properties but sees a message explaining that editing is restricted by **Members & Access**.

<Tip>
  Use Follow-up for a customer note with an optional reminder, Team Inbox Task for internal tracked work, and HubSpot Notes/Tasks/Calls when that information must live on the connected CRM record.
</Tip>
