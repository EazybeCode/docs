---
title: "Create a New Broadcast"
description: "Choose a template and recipients, review the estimated cost, and send a WhatsApp campaign."
---

Create a broadcast from the Eazybe workspace when you want to send one approved WhatsApp template to multiple contacts. You will choose the message, add recipients, and confirm the cost before sending.

<Info>
  Before you start, connect a WhatsApp Business number through Meta, approve a WhatsApp template, and add enough balance to your Eazybe wallet.
</Info>

<Steps>
  <Step title="Open a new broadcast">
    Open **Broadcasts**, then select **New broadcast**. Eazybe opens the **Create broadcast** page.

    ![Broadcasts page with the New broadcast button highlighted](/images/broadcasts/broadcast-workflow-start.jpeg)
  </Step>
  <Step title="Choose the message">
    Complete the first section:

    1. Enter a **Broadcast name**. Only your team sees this name.
    2. Select the WhatsApp Business number in **Send from**.
    3. Select an approved template in **Template message**.
    4. Check the **Message preview** on the right.

    ![Create broadcast screen with Broadcast name, Send from, Template message, and Message preview](/images/broadcasts/create-broadcast-choose-message.png)

    <Note>
      If the template you need is not listed, confirm that Meta has approved it. You can also select **Add new template** to start creating one.
    </Note>
  </Step>
  <Step title="Choose the recipients">
    In **Choose recipients**, select one source:

    - **Upload a list** to add a CSV or Excel file.
    - **HubSpot contact list** to select a synced HubSpot list. This tab appears only when HubSpot is connected.

    ![Choose recipients section with Upload a list and HubSpot contact list tabs](/images/broadcasts/create-broadcast-choose-recipients.jpeg)

    <CardGroup cols={2}>
      <Card
        title={
          <div className="flex flex-col items-start gap-4">
            <Icon icon="file-arrow-up" size={30} className="text-black dark:text-white" />
            <a href="/en/broadcasts/upload-contacts" className="text-primary underline-offset-4 hover:underline">
              Upload a List
            </a>
          </div>
        }
      >
        Prepare the phone number and variable columns before uploading.
      </Card>
      <Card
        title={
          <div className="flex flex-col items-start gap-4">
            <Icon icon="hubspot" size={30} className="text-black dark:text-white" />
            <a href="/en/broadcasts/hubspot-contact-list" className="text-primary underline-offset-4 hover:underline">
              Use a HubSpot List
            </a>
          </div>
        }
      >
        Search for and select one synced HubSpot contact list.
      </Card>
    </CardGroup>
  </Step>
  <Step title="Review and send the broadcast">
    Select the contacts who should receive the message. In the footer, confirm the selected recipient count, sending number, template, and **Estimated cost**. Select **Send broadcast** when the details are correct.

    ![Broadcast footer with one selected recipient, estimated cost, Cancel, and Send broadcast](/images/broadcasts/create-broadcast-review-and-send.jpeg)

    <Warning>
      Sending a broadcast uses wallet balance. Check every template variable and recipient before you send; you cannot recall a submitted campaign from this page.
    </Warning>
  </Step>
</Steps>

After submission, return to **Broadcasts** to monitor delivery. Select **View Analytics** beside the campaign for recipient-level results.
