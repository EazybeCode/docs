---
title: "Troubleshoot Broadcasts"
description: "Resolve common contact upload, HubSpot, template, estimate, and delivery issues."
---

Use the symptom that matches what you see in Eazybe. Complete the checks in order, then reopen the broadcast or refresh the results.

## HubSpot Contact List Is Not Visible

**Cause:** HubSpot is not connected to the current workspace.

**Fix:** Connect HubSpot, return to **Broadcasts**, and reopen **New broadcast**. The **HubSpot contact list** tab appears under **Choose recipients** after the connection is available.

## HubSpot Lists Cannot Be Loaded

**Cause:** The HubSpot connection does not include the `crm.lists.read` permission.

**Fix:** Reconnect HubSpot and approve list access, then reopen **HubSpot contact list**.

## A HubSpot List Is Missing or Still Updating

HubSpot can continue updating an active list after its filters change.

**Fix:** Wait for the update to finish, select **Refresh** in Eazybe, and open the list again. You do not need to sign out.

## No Valid Contacts Were Found

Check the uploaded file or HubSpot properties:

- Include a country code for every phone number.
- In CSV files, keep **Country Code** and **Phone** in separate columns.
- In Excel files, put the full international number in **Phone**.
- Remove spaces and special characters from phone values.
- Fill empty phone cells.
- For HubSpot, add a valid value to `mobilephone` or `phone`.

<Note>
  Eazybe removes duplicate phone numbers automatically, so the valid recipient count can be lower than the number of rows in the source.
</Note>

## Estimated Cost Is Not Displayed

Confirm that you have selected a WhatsApp Business number, an approved **Template message**, and at least one valid recipient. Complete every required variable value or HubSpot property mapping, then wait while **Calculating...** is displayed.

If **Send broadcast** is still unavailable, check that the Eazybe wallet has enough balance.

## Template Parameter Error `#132000`

The values supplied for the message do not match the number of variables in the approved template.

**Fix:**

- For **Upload a list**, add a populated column for every numbered variable.
- For **HubSpot contact list**, complete every required property mapping and fallback value.
- Recheck the **Message preview** before sending again.

## A Message Failed After Sending

Open **View Analytics**, select **Failed**, and review the failure reason for the contact. Select **Export** to download the failed group when you need to correct or share the affected rows.

<Tip>
  If the issue continues, email [support@eazybe.com](mailto:support@eazybe.com) with the campaign name, sending number, failure reason, and a screenshot of the error.
</Tip>
