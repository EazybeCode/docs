title: "How Broadcasts Work"
description: "Follow the broadcast workflow from choosing a template to monitoring delivery."
---

Every broadcast moves through five stages. Follow this page to understand what you select on each screen and what Eazybe does next.

<Steps>
  <Step title="Choose the message">
    Enter an internal **Broadcast name**, select the WhatsApp Business number in **Send from**, and choose an approved **Template message**. The **Message preview** updates when you select a template.

    ![Create broadcast screen with Broadcast name, Send from, Template message, and Message preview](/images/broadcasts/choose-broadcast-message.jpeg)

    <Note>
      Recipients do not see the broadcast name. Only your team uses it to identify the campaign in Eazybe.
    </Note>
  </Step>
  <Step title="Choose the recipients">
    In **Choose recipients**, select **Upload a list** or **HubSpot contact list**. Add the contacts, then select the rows that should receive the campaign.

    ![Choose recipients screen with the Upload a list tab and Choose file button](/images/broadcasts/choose-broadcast-recipients.jpeg)

    <Note>
      **HubSpot contact list** appears only when HubSpot is connected to the current workspace.
    </Note>
  </Step>
  <Step title="Prepare the variable values">
    If the template contains numbered variables such as `{{1}}`, add one matching column for every variable and a value for every contact. A HubSpot property template uses its saved HubSpot mappings.

    ![Spreadsheet with Name, Phone, and three numbered template variable columns](/images/broadcasts/prepare-broadcast-variables.jpeg)

    <Warning>
      The spreadsheet values in this screenshot are examples. Replace them with the values that should appear in each recipient's message.
    </Warning>
  </Step>
  <Step title="Review and send the broadcast">
    Wait for the footer to show the selected recipient count and **Estimated cost**. Confirm the sending number and template, then select **Send broadcast**.

    ![Broadcast footer with one selected recipient, estimated cost, Cancel, and Send broadcast](/images/broadcasts/review-and-send-broadcast.jpeg)

    <Warning>
      Sending uses wallet balance. A submitted campaign cannot be recalled from the Broadcasts page.
    </Warning>
  </Step>
  <Step title="Monitor delivery">
    Return to **Broadcasts** and review the **Total**, **Sent**, **Delivered**, **Read**, and **Failed** totals. Select **View Analytics** for recipient-level status and failure details.

    ![Broadcasts page with delivery totals, campaign status, and View Analytics buttons](/images/broadcasts/monitor-broadcast-delivery.jpeg)

    <Note>
      Delivery totals can change while WhatsApp processes the campaign. Select **Refresh** to load the latest results.
    </Note>
  </Step>
</Steps>

## Recipient Sources

| Source | Use it when |
| --- | --- |
| **Upload a list** | You have recipient data in a `.csv`, `.xls`, or `.xlsx` file |
| **HubSpot contact list** | HubSpot is connected and you want to send to a synced HubSpot list |

Only one recipient source can be used for a broadcast at a time.
