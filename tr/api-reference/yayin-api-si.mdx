## Genel Bakış

Genel Yayın API'si, harici sistemlerin kuruluşunuza ait WhatsApp Business numaralarına erişmesini sağlar. Her istek API anahtarıyla tek bir kuruluş kapsamında değerlendirilir ve kullanılan tüm WABA numaraları bu kuruluşa ait olmalıdır.

`/broadcast/public` altında iki uç nokta grubu bulunur:

- **v2 uç noktaları:** kuruluş kimlik doğrulama anahtarını kullanır ve bu sayfada belgelenir.
- **Eski uç noktalar:** numara başına kullanılan eski WABA anahtarıyla çalışmaya devam eder ve değiştirilmemiştir. Eski uç noktalar bölümüne bakın.

## Temel Yapılandırma

| Ayar | Değer |
| --- | --- |
| **URL** | `https://cerberus.eazybe.com/prod/api/v2` |
| **Temel yol** | `/broadcast/public` |
| **Kimlik doğrulama** | `x-api-key` başlığı |
| **Content-Type** | `application/json` |

## Başlamadan Önce

<Warning>
  **Anahtarı sunucu tarafında tutun.** Bu anahtar, kuruluşunuzun tüm WhatsApp numaralarından gönderim yapılmasına izin verir. Anahtarı ortam değişkenlerinde veya bir gizli anahtar yöneticisinde saklayın; web ya da mobil koda eklemeyin.
</Warning>

<Tip>
  **Buradan başlayın.** Kullanabileceğiniz WABA numaralarını görmek için Telefon numaralarını listele bölümünü, şablonun onaylı olduğunu doğrulamak için Şablonları listele bölümünü kullanın.
</Tip>

## Kimlik Doğrulama

Durum denetimi dışındaki her istekte kuruluşunuzun kimlik doğrulama anahtarını `x-api-key` başlığına iletin. `auth_key`, çalışma alanındaki Staff bölümünde bulunur.

```
x-api-key: your-organization-auth-key
Content-Type: application/json
```

<Frame>
  ![Kuruluş kimlik doğrulama anahtarınızı Staff bölümünde bulun](/images/public-broadcast-api-auth-key.png)
</Frame>

### Anahtar neyi çözüyor?

Anahtar kuruluşunuzu tanımlar. `fromPhoneNumber` veya `phone_number` alan uç noktalarda API ayrıca numaranın söz konusu kuruluşa kayıtlı olduğunu ve WABA kaydının tamamlandığını doğrular; `waba_id`, `phone_number_id`, `phone_number` ve `access_token`'in hepsinin mevcut olması gerekir. Bir uyumsuzluk `403`'i değil, `401`'i döndürür.

## İstek sınırları

Limitler sabit 60 saniyelik bir pencerede sayılır. Çoğunun kapsamı API anahtarınız **ve** istekteki telefon numarasına göre belirlenir; dolayısıyla iki farklı gönderme numarası aynı bütçe için rekabet etmez.

| Uç nokta | Sınırı | Başına sayıldı |
| --- | --- | --- |
| `send-template-broadcast` | 10 / dak | tuşu + fromPhoneNumber |
| `send-freeform` | 20 / dak | tuşu + fromPhoneNumber |
| `templates` | 20 / dak | tuşu + phone_number |
| `phone-numbers` | 30 / dak | anahtar |
| `status` | 30 / dak | anahtar |

### Limitin aşılması

```json
{
  "status": false,
  "status_code": 429,
  "message": "Rate limit exceeded",
  "data": {
    "error": {
      "message": "Rate limit exceeded. Try again in 43 seconds."
    }
  }
}
```

Mesaj size pencerede tam olarak kaç saniye kaldığını söyler. Hemen yeniden denemek yerine bu kadar bekleyin; hemen yeniden denemek hiçbir şey tüketmez ancak aynı hatayı döndürür.

## Telefon numaralarını listele

Kuruluşunuza kayıtlı tüm WhatsApp Business numaralarını listeler. Gönderilen uç noktalarında döndürülen `phone_number`'i `fromPhoneNumber` olarak kullanın.

### Uç Nokta

```http
GET /broadcast/public/phone-numbers
```

### İstek

```bash
curl "$BASE_URL/broadcast/public/phone-numbers" \
  -H "x-api-key: $API_KEY"
```

### Yanıt

**200 — Telefon numaraları başarıyla getirildi**

```json
{
  "status": true,
  "status_code": 200,
  "message": "Phone numbers fetched successfully",
  "data": [
    {
      "phone_number": "14844634680",
      "waba_id": "1099052972334241",
      "phone_number_id": "894234333763517"
    }
  ]
}
```

Boş bir `data` dizisi, anahtarın geçerli olduğu ancak kuruluşa henüz bağlı bir WABA numarası olmadığı anlamına gelir. Bu bir hata değil, yapılandırma durumudur.

## Şablonları listele

Numaralarınızdan birinde mevcut olan onaylanmış WhatsApp şablonlarını döndürür. Bunu bir yayından önce çağırın; onaylanmamış veya yanlış yazılmış bir şablon adı göndermek tüm isteği başarısızlığa uğratır.

### Uç Nokta

```http
GET /broadcast/public/templates
```

### Sorgu parametreleri

| Parametre | Tür | Gerekli | Açıklama |
| --- | --- | --- | --- |
| `phone_number` | dize | Gerekli | Kuruluşunuza ait bir WABA numarası, yalnızca rakamlar |

### İstek

```bash
curl "$BASE_URL/broadcast/public/templates?phone_number=14844634680" \
  -H "x-api-key: $API_KEY"
```

### Yanıt

**200 — Şablonlar başarıyla getirildi**

```json
{
  "status": true,
  "status_code": 200,
  "message": "Templates fetched successfully",
  "data": [
    {
      "name": "eazybe_temp",
      "status": "APPROVED",
      "category": "MARKETING",
      "language": "en",
      "components": [
        { "type": "BODY", "text": "Hello {{1}}, your code is {{2}}." }
      ]
    }
  ]
}
```

Gövdedeki `{{n}}` yer tutucularını sayın; bu, her bir alıcının `templateParams` dizisinin tam olarak sağlaması gereken değer sayısıdır.

## Şablon yayınını gönder

Onaylanmış bir şablonu alıcı listesine gönderir. Liste boyutuna göre davranış değişiklikleri: 1.000 alıcıya kadar yayın eşzamanlı olarak kuyruğa alınır; bunun üzerinde parçalara bölünür ve durum için yoklama yaptığınız bir arka plan işi olarak işlenir.

### Uç Nokta

```http
POST /broadcast/public/send-template-broadcast
```

### Başlıklar

| Başlık | Gerekli | Açıklama |
| --- | --- | --- |
| `x-api-key` | Gerekli | Kuruluş kimlik doğrulama anahtarı |
| `Content-Type` | Gerekli | `application/json` |
| `Idempotency-Key` | İsteğe bağlı | Benzersiz dize, tekrar denemek güvenli |

### Gövde

| Alan | Tür | Gerekli | Açıklama |
| --- | --- | --- | --- |
| `broadcastName` | dize | Gerekli | Raporlamada gösterilen kampanya etiketi |
| `fromPhoneNumber` | dize | Gerekli | WABA numaranız, Telefon numaralarını listele |
| `templateName` | dize | Gerekli | Onaylanan şablon adı |
| `templateLanguage` | dize | Gerekli | Dil kodu, ör. `en` |
| `templateType` | dize | Gerekli | `MARKETING`, `UTILITY` ve benzeri |
| `templateId` | dize | İsteğe bağlı | WhatsApp şablon kimliği |
| `globalTemplateParams` | dize[] | İsteğe bağlı | Kendi parametreleri olmayan alıcılara uygulanan varsayılanlar |
| `data` | nesne[] | Gerekli | Alıcılar, 1 - 10.000 |

### Alıcı nesnesi

| Alan | Tür | Gerekli | Açıklama |
| --- | --- | --- | --- |
| `countryCode` | dize | Gerekli | Yalnızca rakamlar, `+` yok. örneğin `91` |
| `toPhoneNumber` | dize | Gerekli | Yalnızca rakamlar, ülke kodu olmadan |
| `templateParams` | dize[] | İsteğe bağlı | `{{1}}`, `{{2}}`… değerleri Genel değerleri geçersiz kılar. |

### İstek

```bash
curl -X POST "$BASE_URL/broadcast/public/send-template-broadcast" \
  -H "x-api-key: $API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: festive-run-1" \
  -d '{
    "broadcastName": "Festive Offer Campaign",
    "fromPhoneNumber": "14844634680",
    "templateName": "eazybe_temp",
    "templateLanguage": "en",
    "templateType": "MARKETING",
    "templateId": "1530766784804741",
    "globalTemplateParams": ["Valued customer", "FESTIVE10"],
    "data": [
      {
        "countryCode": "91",
        "toPhoneNumber": "9675360316",
        "templateParams": ["Vineet", "VIP20"]
      },
      {
        "countryCode": "91",
        "toPhoneNumber": "8077378155"
      }
    ]
  }'
```

Bu örnekte ilk alıcı kendi değerlerini alır ve ikincisi `globalTemplateParams`'e geri döner.

### Yanıtlar

**200 — Sıraya alındı (1.000 alıcı veya daha az)**

```json
{
  "status": true,
  "status_code": 200,
  "message": "Bulk broadcast queued successfully",
  "data": { }
}
```

**202 — Arka planda işleme için kabul edildi (1.000'den fazla alıcı)**

```json
{
  "status": true,
  "status_code": 202,
  "message": "Broadcast accepted for background processing",
  "data": {
    "jobId": "pub_4f8c2a1e9b7d43c6a5e0f2b18d3c9a67",
    "status": "PROCESSING",
    "totalRecipients": 1001,
    "chunkSize": 1000,
    "totalChunks": 2
  }
}
```

`jobId`'i saklayın; yayının nasıl bittiğini kontrol etmenin tek yolu budur. Anket Bununla yayın durumunu alın.

**400 — Alıcı sınırı aşıldı**

```json
{
  "status": false,
  "status_code": 400,
  "message": "Recipient limit exceeded",
  "data": {
    "error": {
      "message": "Template broadcast cannot exceed 10000 recipients per request."
    }
  }
}
```

**400 — Şablon onaylanmadı**

```json
{
  "status": false,
  "status_code": 400,
  "message": "Template is not approved or not found",
  "data": {
    "error": {
      "message": "Template is not approved or not found for this WABA phone number."
    }
  }
}
```

<Warning>
  **Yinelenen alıcılar reddedilir, birleştirilmez.** Aynı `countryCode` + `toPhoneNumber` çifti iki kez görünürse, kopyanın dizinini adlandıran bir `400` ile isteğin tamamı başarısız olur. Göndermeden önce listenizi tekilleştirin.
</Warning>

## Serbest biçimli mesaj gönder

Bir alıcıya tek bir mesaj gönderir. Sekiz içerik türünün tamamı bu uç noktayı paylaşır; `type` alanı diğer hangi alanların gerekli olduğuna karar verir.

### Uç Nokta

```http
POST /broadcast/public/send-freeform
```

### Ortak alanlar

| Alan | Tür | Gerekli | Açıklama |
| --- | --- | --- | --- |
| `fromPhoneNumber` | dize | Gerekli | WABA numaranız |
| `toPhoneNumber` | dize | Gerekli | Ülke kodunu içeren alıcı, yalnızca rakamlar |
| `type` | dize | Gerekli | Aşağıdaki sekiz türden biri |

### Türe özgü alanlar

| `type` | Gerekli | İsteğe bağlı | Kabul edilen dosya uzantıları |
| --- | --- | --- | --- |
| `text` | `text` | — | — |
| `image` | `url` | `caption` | jpg, jpeg, png |
| `document` | `url` | `name`, `caption` | pdf, txt, doc, docx, ppt, pptx, xls, xlsx |
| `audio` | `url` | — | aac, amr, mp3, m4a, mp4, ogg, opus |
| `video` | `url` | `caption` | mp4, 3gp |
| `sticker` | `url` | — | webp |
| `location` | `latitude`, `longitude` | `name`, `address` | — |
| `interactive` | `interactive` | — | — |

<Warning>
  **Uzantı, dosyadan değil, URL yolundan okunur.** `.webp` ile biten bir URL'den sunulan gerçek bir PNG, `image` için reddedilir ve hiçbir uzantısı olmayan bir URL, her medya türü için reddedilir. Sorgu dizeleri göz ardı edildiğinden `…/photo.png?v=2` uygundur.
</Warning>

## Yayın durumunu al

`202` ve `jobId` döndüren büyük bir yayın işinin ilerlemesini döndürür. 1.000 veya daha az alıcının olduğu yayınlar iş yaratmaz ve oylanacak hiçbir şey yoktur.

### Uç Nokta

```http
GET /broadcast/public/status/:jobId
```

### İstek

```bash
curl "$BASE_URL/broadcast/public/status/pub_4f8c2a1e9b7d43c6a5e0f2b18d3c9a67" \
  -H "x-api-key: $API_KEY"
```

### Yanıtlar

**200 — iş kaydı artı parça ilerlemesinin özeti**

```json
{
  "status": true,
  "status_code": 200,
  "message": "Broadcast status fetched successfully",
  "data": {
    "jobId": "pub_4f8c2a1e9b7d43c6a5e0f2b18d3c9a67",
    "status": "QUEUED_FOR_PROCESSING",
    "totalRecipients": 1001,
    "totalChunks": 2,
    "summary": { }
  }
}
```

**404** — Yayın işi bulunamadı

**401** — İş farklı bir kuruluşa ait

Başka bir kuruluş tarafından oluşturulan bir iş, `404` yerine `401` değerini döndürür; iş kimlikleri kuruluşlar arasında numaralandırılamaz.

## Doğrulama kuralları

Bunlar, herhangi bir şey WhatsApp'a ulaşmadan önce çalışır, dolayısıyla buradaki reddetme mesaj kotasına neden olmaz. Her başarısızlık, `message: "Validation error"` ile `400`'i ve belirli bir nedeni döndürür.

| Kural | Şunlar için geçerlidir | Arıza durumunda |
| --- | --- | --- |
| Telefon numaraları yalnızca rakam olmalıdır; `+`, boşluk veya kısa çizgi olmamalıdır | Her ikisi de uç noktalar gönderir | Geçersiz `toPhoneNumber` / `countryCode` |
| En az bir alıcı | Şablon yayını | Alıcı listesi gerekli |
| Yinelenen `countryCode` yok • `toPhoneNumber` | Şablon yayını | *n* dizininde yinelenen alıcı bulundu |
| Maksimum 10.000 alıcı | Şablon yayını | Alıcı sınırı aşıldı |
| Şablon mevcut olmalı ve bu numara için onaylanmış olmalıdır | Şablon yayını | Şablon onaylanmadı veya bulunamadı |
| `text` boş olmayan bir dize olmalıdır | Serbest biçimli, `text` yazın | kısa mesajlar için metin gereklidir |
| `url` http veya https olmalıdır | Serbest biçimli medya türleri | URL geçerli bir http veya https URL'si olmalıdır |
| URL uzantısı izin verilenler listesinde olmalıdır | Serbest biçimli medya türleri | Kabul edilen uzantıları listeler |
| Enlem −90 ila 90, boylam −180 ila 180, her iki sayı | Serbest biçimli, `location` yazın | Sorunlu koordinatın adını veriyor |
| Etkileşimli tür `button` veya `list` olmalıdır | Serbest biçimli, `interactive` yazın | etkileşimli tür düğme veya liste olmalıdır |
| 1 ila 3 düğme | Etkileşimli düğmeler | 3 düğmeyi aşamaz |
| Tüm bölümlerde 1 ila 10 satır | İnteraktif liste | 10 satırı aşamaz |

## Hatalar

Her hata aynı zarfı kullanır:

```json
{
  "status": false,
  "status_code": 400,
  "message": "Short summary",
  "data": {
    "error": {
      "message": "Specific detail about what to fix"
    }
  }
}
```

### Durum kodları

| Kod | Anlamı | Ne yapmalı |
| --- | --- | --- |
| `200` | Sıraya alındı ​​veya getirildi | — |
| `202` | Büyük yayın kabul edildi | `jobId` ile durumu sorgulayın |
| `400` | Doğrulama veya limit hatası | `data.error.message`'i okuyun ve yükü düzeltin |
| `401` | Anahtar, numara veya iş sahipliği sorunu | Aşağıdaki tabloya bakın |
| `404` | Yayın işi bulunamadı | `jobId`'i kontrol edin |
| `409` | Aynı `Idempotency-Key` hâlâ işleniyor | Bekleyin ve durumu sorgulayın; yeniden göndermeyin |
| `429` | Oran sınırı aşıldı | Mesajda belirtilen saniyeleri bekleyin |
| `500` | Alt sistem gönderimi başarısız | Aynı `Idempotency-Key` ile yeniden deneyin |
| `503` | Kimlik doğrulama veritabanı zaman aşımına uğradı | Geri alma ile yeniden deneyin |

### Dört 401

Dördü de `401` değerini döndürür ancak farklı anlamlara gelir:

| Mesaj | Sebep | Düzelt |
| --- | --- | --- |
| API anahtarı gerekli | `x-api-key` başlığı yok | Başlığı ekleyin |
| Geçersiz API anahtarı. Organizasyon bulunamadı. | Hiçbir kuruluşta `auth_key` | Anahtarı ve doğru ortamda olduğunuzu kontrol edin |
| Bu kuruluşa ait WABA hesabı bulunamadı. | Numara kuruluşunuza kayıtlı değil | Telefon numaralarını al |
| WABA hesabı eksik. Eksik alanlar: … | WABA kaydında `waba_id`, `phone_number_id`, `phone_number` veya `access_token` eksik | Bu numara için WABA'ya katılımı tamamlayın |

<Note>
  **Yeniden deneme politikası.** Üstel geri çekilme ile `500` ve `503`'i yeniden deneyin. `400` veya `401`'i hiçbir zaman yeniden denemeyin; aynı istek aynı şekilde başarısız olur. `429`'te yanıtta belirtilen süre kadar bekleyin. Yeniden denemeyi düşündüğünüz isteklerde her zaman bir `Idempotency-Key` gönderin.
</Note>

## Eski uç noktalar

<Warning>
  **Farklı kimlik doğrulama.** Bu üçü v2'den öncedir ve kuruluşunuzun `auth_key`'ini değil, hâlâ sayı başına eski WABA anahtarını kullanır. Bunlar değişmemiştir ve desteklenmeye devam etmektedir ancak yeni entegrasyonlar yukarıdaki v2 uç noktalarını kullanmalıdır.
</Warning>

```
POST /broadcast/public/generate-key      no auth · 5/min
```

Bir telefon numarası için eski bir API anahtarı oluşturur. Kuruluş kimliğini değil `phoneNumber`'i alır.

```json
{ "phoneNumber": "919876543210" }
```

```
POST /broadcast/public/send-single       legacy key · 30/min
```

Bir şablon mesajı gönderir. Alıcı alanları `data` dizisi yerine en üst düzeyde bulunur.

```
POST /broadcast/public/send-bulk         legacy key · 10/min
```

Toplu şablon gönderimi, **1.000** alıcıyla sınırlıdır; parçalama ve iş kimliği yoktur. Sınırın aşılması, atan v2 uç noktasının aksine, yanıt gövdesinde bir HTTP 200 durum satırıyla `400`'i döndürür.
