title: "Instant Webhook"
description: "Recibe eventos de WhatsApp Business en un callback HTTPS suscribiendo una WABA mediante la API de Eazybe."
---

Instant Webhook conecta una cuenta de WhatsApp Business (WABA) con un callback HTTPS para que tu sistema reciba eventos de mensajes entrantes y entrega cuando ocurren. Utiliza los endpoints de suscripción de **Wrapper de API Meta** para crear y gestionar la conexión.

<Info>
  Esta página es una descripción general. Los campos, esquemas de respuesta, autenticación y errores se mantienen en las páginas enlazadas de la referencia WABA.
</Info>

## Cómo funciona

1. El callback debe estar disponible mediante HTTPS.
2. Al crear la suscripción, Meta envía una solicitud de verificación.
3. El callback debe validar el token compartido y devolver `hub.challenge`.
4. Tras la verificación, la WABA envía al callback los eventos entrantes y de entrega compatibles.

<Warning>
  Eliminar la suscripción detiene los eventos de mensajes entrantes y entrega de esa WABA. Comprueba el ID de la WABA y el callback antes de cambiar una suscripción de producción.
</Warning>
