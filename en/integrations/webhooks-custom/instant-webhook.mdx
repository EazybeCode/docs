Instant Webhook connects a WhatsApp Business Account (WABA) to an HTTPS callback so your system can receive inbound message and delivery events as they occur. Use the webhook-subscription endpoints in **Waba Api Documentation** to create and manage this connection.

<Info>
  This page is an overview. Request fields, response schemas, authentication, and error handling are maintained in the linked Waba API reference pages.
</Info>

## How it works

1. Your callback URL must be available over HTTPS.
2. When you create the subscription, Meta sends a verification request to the callback.
3. Your callback must validate the shared verify token and return `hub.challenge`.
4. After verification, the WABA sends supported inbound and delivery events to the callback.

<Warning>
  Removing the subscription stops inbound message and delivery events for that WABA. Confirm the WABA ID and callback before changing a production subscription.
</Warning>
