Instant Webhook conecta uma Conta do WhatsApp Business (WABA) a um callback HTTPS para que seu sistema receba eventos de mensagens recebidas e entrega assim que ocorrem. Use os endpoints de assinatura do **Wrapper da API Meta** para criar e gerenciar a conexão.

<Info>
  Esta página é uma visão geral. Campos, esquemas de resposta, autenticação e erros são mantidos nas páginas vinculadas da referência WABA.
</Info>

## Como funciona

1. O callback deve estar disponível por HTTPS.
2. Ao criar a assinatura, a Meta envia uma solicitação de verificação.
3. O callback deve validar o token compartilhado e retornar `hub.challenge`.
4. Após a verificação, a WABA envia os eventos recebidos e de entrega compatíveis ao callback.

<Warning>
  Remover a assinatura interrompe os eventos de mensagens recebidas e entrega dessa WABA. Confira o ID da WABA e o callback antes de alterar uma assinatura de produção.
</Warning>
