## Use the Inbox lists

Open **Lists** and choose the queue that matches your work.

| Inbox list | What it shows |
|---|---|
| **All conversations** | Every conversation currently available to you. |
| **Favorites** | Conversations marked with a star. |
| **Assigned** | Conversations that have an owner. This list is not shown to Employee-role users. |
| **Unassigned** | Conversations that do not have an owner. This list is not shown to Employee-role users. |
| **Assign to me** | Conversations already assigned to the signed-in user. Selecting this list does not assign a new conversation. |
| **Closing window** | WABA conversations whose 24-hour messaging window is open and has no more than about two hours remaining. Expired chats are excluded. |

Counts beside a list show how many conversations are currently in it. You can collapse an individual section or the entire Lists panel.

Additional lists can appear for AI labels, advertisements, broadcast workflows, and AI-agent stages. See [Start New Chats and Review Acquisition Conversations](/en/team-inbox-hd/new-chats-and-acquisition-en) and [Use AI Features](/en/team-inbox-hd/ai-features-en).

## Search by name or phone number

Enter a customer name or phone number in **Search conversations**. Search works inside the selected list and together with active filters.

Select the **x** in the search field to remove only the search text. The selected list and other filters remain active.

<Info>
  **Add image here:** Add a screenshot showing a name/number search and the x clear control. Save it as `/images/team-inbox/search-conversations.png`.
</Info>

The conversation list loads more results as you scroll. If a search result is not in the first set of conversations, continue scrolling or remove restrictive filters.

## Use quick filters

Quick filters appear on standard Inbox lists such as All conversations, Favorites, Assigned, Unassigned, Assign to me, and Closing window. They are not shown for specialized AI-label, advertisement, broadcast, or AI-agent-stage results.

### Filter by Channels

**Channels** limits results to one or more WhatsApp numbers you can access.

| Badge | Meaning |
|---|---|
| **APP** | A WhatsApp or WhatsApp Business App number synchronized with Eazybe. |
| **API** | An official WhatsApp Business API number. |
| **COEX** | A coexistence number used with both WhatsApp Business App and Cloud API. |

A disconnected marker identifies a number that needs to be reconnected. You may still be able to read its existing history, but sending is unavailable.

## Use All filters

Open **All filters** for expiry time, advanced assignment rules, channels, and configured AI customer properties.

</Info>

### Available properties

| Property | Examples |
|---|---|
| **Expire time** | Less than 3 hours, less than 6 hours, or less than 12 hours before the WABA messaging window closes. |
| **Assignee** | One or more team members, any known owner, or no owner. |
| **Channels** | One or more APP, API, or COEX numbers. |
| **AI properties** | Workspace-defined details such as urgency, issue category, lead stage, or another configured customer field. Availability depends on plan and role. |

### Operators

| Operator | Result |
|---|---|
| **is any of** | Includes a conversation if its value matches at least one selected value. |
| **is none of** | Excludes a conversation if its value matches any selected value. |
| **is known** | Includes conversations where the property has a value. |
| **is unknown** | Includes conversations where the property has no value. |

**Expire time** and **Channels** use **is any of** or **is none of**. Assignee and supported AI properties can also use **is known** and **is unknown**.

### Combine conditions with AND and OR

Conditions inside one group use **AND** logic: a conversation must match every condition in that group.

For example, **Channels is any of Support API AND Assignee is unknown** finds unassigned conversations on that number.

Select **+ Add condition** to make the current group more specific. Select **+ Add OR group** when either group can match.

For example, one result can include **unassigned conversations on Support API OR conversations assigned to the Sales Manager**.

Saved views appear under **My views** in Lists. Select a view to restore it. If you change a selected view, Team Inbox shows **Unsaved changes**; select **Update view** to replace its saved filter configuration.

<Note>
  Saved views are currently private to their creator. Shared workspace views are not available in the current Team Inbox interface. Saved views are not shown to Employee-role users.
</Note>

## Clear filters

- Select **Clear filters** in the full editor to remove all conversation-filter conditions.
- Select **Clear** in the saved-view result bar to leave the saved view and return to unfiltered **All conversations**.
- Clear the search field separately if it still contains text.

## If the result is empty

Check these items in order:

1. Clear the search text.
2. Open **All filters** and remove one condition at a time.
3. Put alternatives in separate OR groups instead of the same AND group.
4. Confirm the selected channel is connected and available to you.
5. Confirm the conversation belongs to the currently selected list.

<Tip>
  Use **Closing window** for the most urgent open WABA conversations. Use the 3-, 6-, or 12-hour **Expire time** values when you need a wider planning window.
</Tip>
