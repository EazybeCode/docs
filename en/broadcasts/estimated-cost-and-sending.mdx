## When the Estimate Appears

Eazybe calculates the estimate after you have selected:

- A WhatsApp Business number in **Send from**
- An approved **Template message**
- At least one valid recipient
- A value or mapping for every required template variable

While the request is processing, the footer displays **Calculating...**. When the calculation finishes, it shows the valid recipient count and **Estimated cost**.

<Info>
  The displayed amount is an estimate. The final charge can depend on the template category, the recipient's country, and WhatsApp pricing.
</Info>

## HubSpot Estimate Fallback

Eazybe normally validates the contacts in the selected HubSpot list. If HubSpot temporarily rate-limits that validation, Eazybe can show an approximate estimate based on:

`Segment size × unit price`

The interface identifies the amount as approximate when exact contact validation is unavailable.

## Send the Broadcast

<Steps>
  <Step title="Check the footer">
    Confirm the recipient count, template, sending number, and **Estimated cost**. If the count is wrong, return to the contact table and change the selection.

    ![Broadcast footer with one selected recipient, estimated cost, Cancel, and Send broadcast](/images/broadcasts/create-broadcast-review-and-send.jpeg)
  </Step>
  <Step title="Submit the campaign">
    Select **Send broadcast**. Wait for Eazybe to finish submitting the request before you leave or refresh the page.

    ![Create broadcast screen with the Send broadcast button in the footer](/images/broadcasts/review-and-send-broadcast.jpeg)

    <Warning>
      Sending uses wallet balance. A submitted campaign cannot be recalled from this page.
    </Warning>
  </Step>
</Steps>

If **Send broadcast** is unavailable, confirm that the broadcast has a name, number, approved template, valid recipient, complete variable values, and enough wallet balance.
