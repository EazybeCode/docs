## Understand the WABA 24-hour window

A WhatsApp Business API conversation has a customer-service window that opens after the customer messages the business.

| State | What Team Inbox shows | How to send |
|---|---|---|
| **Open** | A countdown timer, normal composer, and a note that templates are also available. | Send text/files or an approved template. |
| **Closing soon** | The timer becomes more prominent as time runs down. The **Closing window** list includes open chats with about two hours or less remaining. | Reply before expiry or use a template later. |
| **Critical** | The timer uses critical styling near expiry. | Send immediately if a normal reply is required. |
| **Expired** | The normal composer is replaced by a banner explaining that only WABA templates can be delivered. | Select **Send template**. |
| **Disconnected** | History remains available with **Reconnect this WABA to reply**. | Reconnect the number first. |

The broader **Expire time** filter can find open windows closing in less than 3, 6, or 12 hours.

<Warning>
  A normal message cannot reopen an expired WABA conversation. Send an approved template and wait for the customer to respond before continuing with normal replies.
</Warning>

### Find and sort Quick Replies

Search by reply content, name, or the visible `/shortcut`. Sort the list by:

- Newest first or Oldest first
- Personal first or Shared first
- Title A–Z or Title Z–A

The scope on each reply explains who can use it: personal, organization, or a selected team.

### Quick Reply variables

Use the variable picker to insert supported customer or sender information. Available sources can include:

- Agent name and chat/customer name
- Eazybe profile information
- HubSpot contact properties when HubSpot is connected and a contact is linked

The value is resolved for the current conversation at sending time. If a value is unavailable or unsupported for that sending method, Team Inbox warns you rather than silently sending incorrect content.

### Attachments in Quick Replies

Quick Replies can include supported images, video, audio, and common document types. WABA applies additional format rules; for example, OGG and recorded quick-reply attachments are not supported in that workflow.

An attached Quick Reply is sent directly, so review its content and recipient before selecting it. Direct sending is unavailable after the WABA window expires; use an approved template instead.

### Edit or delete a Quick Reply

Use a reply's menu to edit its content or delete it. Deleting requires confirmation. Access to shared replies follows their organization or team scope.

## Know what was sent

After sending, use the message indicator to check whether it is pending, sent, delivered, read, or failed. For file messages, the conversation shows an optimistic preview while the send completes.

<Tip>
  For an expired WABA chat, do not use a direct-send Quick Reply. If the wording is reusable, create or choose an approved WhatsApp template with the same intent.
</Tip>
