## Find a broadcast

Use the controls at the top of the page to:

- Search by broadcast name
- Select a WhatsApp Business number
- Filter by source
- Filter by status
- Refresh the latest results

## Understand the columns

| Column | What it shows |
| --- | --- |
| **Broadcast** | Campaign name, source, and template |
| **Total** | Sent + Delivered + Read + Failed |
| **Sent** | Messages accepted for sending |
| **Delivered** | Messages delivered to recipients |
| **Read** | Messages opened by recipients |
| **Failed** | Messages that could not be delivered |
| **Date** | Date the campaign was sent |
| **Status** | Completed, In progress, or Failed |
| **View Analytics** | Recipient-level campaign details |

## Broadcast sources

The source under each campaign tells you where it was created, such as:

- Workspace
- HubSpot segment
- HubSpot workflow
- HubSpot contact
- Zoho
- Salesforce

## Pagination

Choose 25, 50, or 100 broadcasts per page. Use the page controls to move through older campaigns.

<Tip>
  Select **Refresh** when a recent campaign is still in progress or its delivery counts have changed.
</Tip>
