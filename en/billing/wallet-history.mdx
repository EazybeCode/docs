title: "Review Wallet History"
description: "Find wallet transactions, payment status, running balances, and available invoices."
---

Use **Settings → Billing → Wallet history** to review credit purchases and wallet usage. The transaction list helps you confirm whether a payment completed and how each credit or debit changed the balance.

<Note>
  **Wallet history** is available to eligible workspace admins with Credits access. Ask a workspace admin if the tab is not visible.
</Note>

## Find a Transaction

1. Open **Settings → Billing → Wallet history**.
2. Filter by **Completed**, **Pending**, or **Failed**, or choose a date range.
3. Find the row that matches the payment or wallet activity.
4. Review its date, description, credit or debit amount, balance after the transaction, payment status, and invoice availability.

<Note>
  A credit adds funds to the wallet. A debit records wallet usage. The balance after the transaction helps you understand the order in which wallet activity occurred.
</Note>

## Download an Invoice

Use the invoice download action in a transaction row when it is available. A transaction can lack an invoice while payment is pending or when that activity does not create one.

## Understand Payment Status

| Status | What to do |
| --- | --- |
| **Completed** | Confirm that the amount and balance are correct; download the invoice when available |
| **Pending** | Wait for the payment provider to finish processing before trying again |
| **Failed** | Review the failure information, correct the payment method if needed, and start a new purchase only after the failure is confirmed |

<Warning>
  Do not repeat a purchase while its status is **Pending**. Starting another checkout can create a duplicate charge if the first payment later succeeds.
</Warning>

## If a Transaction Is Missing

Select **Refresh** once and check the date range and status filters. If a successful payment is still missing, contact Eazybe Support with the workspace name, amount, currency, payment reference, and payment time.
